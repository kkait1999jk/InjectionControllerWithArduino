## 1. 大学院で学んだこと（研究課題と取り組み）

### 研究テーマ
**「嗅覚ディスプレイを仮想空間で有効活用するための制御と安定化」**

### 背景と技術的課題
* **従来装置の制限**: 従来の嗅覚提示装置は専用ソフトウェアでの動作に限られており、Unity等の仮想空間エンジンからの動的な制御が困難であった。
* **動作の不安定性**: 既存の制御DLLを介して外部アプリケーションから駆動する際、全オフ制御等の特定操作でアプリケーションがフリーズ・強制終了する問題が存在した。

### 解析・検証プロセス（ブラックボックス解析）
* **動作原理の解明**: インターフェースボックス制御関数（`TUSBKRL_Set`）の内部仕様・挙動が不透明であったため、引数（0〜15）と出力ケーブルへの電圧印加パターンの関係を網羅的に検証。
* **ロジックの可視化**: データ解析の結果、二進数表記のビット左右反転処理および各桁と出力ピンの対応関係を解明。

### 開発実績・成果
* **C#機器制御プログラム（`Injection.cs`）**: Visual Studio（C#）を用いて、全8パターンの電圧印加をミリ秒精度で安定して制御するロジックを自作・実装。
* **ファン制御プログラム（`FanController.cs`）**: `System.IO.Ports.SerialPort` を介してArduinoとシリアル通信を行い、PWM制御で送風ファンの風量（匂い拡散）を精密に調整する機構を構築。
* **成果**: 外部アプリケーションからフリーズなく安全・正確に駆動できる機器制御基盤を確立。

### 主要テクニカルスキル詳細

#### ① C# / .NET によるシステム・ツール開発
* `Stopwatch` クラスを用いたミリ秒単位の精密タイマー制御およびマルチスレッド処理
* 音声処理（`SoundPlayer`）やGUI/CLIツールの構築
* 例外処理（`try-catch-finally`）および安全なリソース解放の実装

* ビット演算・パターン抽出による制御構造の特定と安定化ロジックの構築
